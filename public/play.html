    Netplay — jouer à deux
    1. Les deux joueurs ouvrent exactement le même jeu (même console + même fichier).
    2. Cliquez l’icône 🌐 dans la barre de l’émulateur (en bas).
    3. Hôte : crée une salle (nom + mot de passe optionnel).
    4. Invité : rafraîchit la liste et rejoint la salle.
    5. Manette Xbox : appuie sur A sur cette page, puis mappe dans ⚙️ → Contrôles si besoin.

    Astuce test 2 PC : même Wi‑Fi = plus stable. Hors LAN, le TURN est utilisé automatiquement. DS/N64 : l’hôte doit avoir une machine correcte (le flux vidéo part de l’hôte).

    Clavier : flèches + X/Z/S/A · Entrée = Start · Maj = Select. Manette : menu ⚙️ → Contrôles pour mapper les boutons. DS / N64 / PSP : si ça rame, active le frame skip dans ⚙️ ou passe en mode compatibilité.
